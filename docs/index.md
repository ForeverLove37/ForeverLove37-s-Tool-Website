# Welcome to My Server Toolkit

This is a private collection of shell scripts for DevOps, VPS maintenance, and system configuration.
These scripts are designed to be executed directly from the command line using `curl`.

---

## Quick Start (Usage Guide)

You don't need to download the file manually. Just use the **Short Command** provided below.

### The Syntax
The generic syntax for this repository is:
```bash
curl -L your-main-domain.com/<script_name> | bash
```

### Prerequisites
* **OS**: Debian 10+, Ubuntu 20.04+, or CentOS 7+
* **User**: Root access (or sudo) is required for most installation scripts.
* **Dependencies**: `curl` and `bash` must be installed.
    * Debian/Ubuntu: `apt update && apt install curl -y`

## Script Repository

### 1. Docker Environment
**Script Name:** `docker`
**Description:** Automates the installation of Docker CE and Docker Compose (Plugin). It also configures the log rotation to prevent disk overflow.

**One-Click Install:**
```bash
curl -L https://tool.zengjunjie.com/docker | bash
```

### 2. System Information (Benchmark)
**Script Name:** `info`
**Description:** Displays comprehensive system information including CPU model, Kernel version, IP address (masked), and disk usage. Good for verifying new VPS purchases.

**Run Benchmark:**
```bash
curl -L your-main-domain.com/info | bash
```

### 4. Network Optimization (BBR)
**Script Name:** `bbr`
**Description:** Enables TCP BBR congestion control to improve network speed on high-latency links.

**Enable BBR:**
```bash
curl -L https://tool.zengjunjie.com/bbr | bash
```
### 5. Docker Image Accelerator (ONLY USEFUL IN CN)
**Description:** Fix `i/o timeout` errors when pulling images in China by configuring registry mirrors.

**Command:**
```bash
curl -L https://tool.zengjunjie.com/mirror | bash
```
